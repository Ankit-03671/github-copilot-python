Framework: Keep Flask as the backend framework and preserve the existing application behavior.
Code Structure: Refactor the code into small, reusable, readable functions.
Naming: Use clear and descriptive function and variable names.
Comments: Add simple comments where they improve code understanding.
Error Handling: Use simple and clear error handling with user-friendly messages.
Sudoku Logic: Keep Sudoku generation and validation logic in sudoku_logic.py.
Flask Routes: Keep Flask routes and API handling in app.py.
Testing: Use pytest for automated testing.
Test Structure: Create a tests/ folder and test Sudoku generation, validation, difficulty levels, and Flask routes.
Preserve Functionality: Do not change working application behavior unnecessarily.
Copilot Review: Review every Copilot suggestion before accepting it.
Reject Bad Suggestions: Modify or reject suggestions that do not meet the project requirements.
Dependencies: Avoid unnecessary libraries or frameworks.
